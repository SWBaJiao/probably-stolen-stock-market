# 负债开局适配边界验证

执行 `dotnet run --project Tests/StartingDebt.Tests`。

项目直接编译生产代码 `Game/StartingDebtScenario.cs` 和完整领域代码，使用最小宿主替身提供原版开局注册、店铺现金、日期和保存写回边界。验证回调发生在最终存档身份及天赋资金就绪之前时不会提前改钱，正式保存前才一次性建立债务，并覆盖保存重试、切档，以及 Attach 附加基线、建立债务、移除 pending 三处写回的失败回滚。

宿主替身将领域 JSON 直接作为保存字符串，覆盖字典键及字符串恢复，不覆盖生产 SaveEnvelope 的真实序列化。测试不会启动 Unity，也不验证原版目录的实际渲染、教程执行或游戏回调顺序。这些仍需正式版游戏内验收。
