## 数值口径与证据

表中百分比是该事件对该公司的**一次主冲击目标**，不是商品价格变化，也不是连续每天重复的涨跌；没列出的公司对该事件直接为 0。股票报价保留 2 位小数，落地会有分币量化误差；每日基础行情、前日商铺成交、其他事件会共同影响最终价格。

事件 ID、商品类型及修正幅度由本机 `GameAssembly.dll` 原生工厂静态反汇编确认，事件含义由游戏中文本地化表确认。IL2CPP dummy 程序集只用于定位方法地址、字段偏移，未将空方法体当作原生逻辑。另以原生 StoreEvent 构造调用交叉检查 54 处，其中 1 处为 QueueEvent 内联构造同一个证物库失窃事件，因此独立事件是 53 个。静态存在不代表每个事件在当前存档/试玩流程中都能触发。

幅度使用实际部署位置的 `UserData/MelonModTemplate/market-config.json`，经当前源码 `MarketConfig.Deserialize` 完成默认值补齐与旧默认迁移，再由真实 `EventImpactResolver.EnsureRule` 逐项计算，未用另一套近似公式替代。

显式规则优先，目前 3 条：营养果歉收、非法武器走私货物、武器需求增加。其余按商品类型修正推导：

```text
公司主冲击 = clamp(-Σ(同类型商品修正合计/100 × 公司权重 × 0.5), -15%, +15%)
```

同类型修正先合并并限制在 ±100%；不同类型贡献累加后才对公司限幅。事件没有对同属一个行业的 WATER/净水用品或 WEAPON/ARMOR 取平均。没有已映射调价又没有显式规则时，直接股价影响为 0。

本机旧配置里的秘密动员仍是 +12%/+7%/+5%，但其内容完全匹配旧默认，加载器会在内存升级为 −12%/−7%/−5%；不会改写用户文件。下面按升级后的有效规则列示。

## 需要优先处理的问题

1. **需求与供给混用。** 武器需求增加、假货查获后的正品需求、帮派战争及交火后的医疗需求，不能仅因商品涨价就给供应商统一利空。需要显式区分订单收益、供货成本与社会秩序风险。免费援助、走私货到港的低价也不保证每个供应商盈利，应区分渠道与竞争者。

2. **轻微事件与严重事件幅度接近。** 计划水处理维护的清泉 −15% 等于严重水泵故障上限；发电站例行检修令霆光 −10.725%。新闻都强调有限/轻微影响，建议独立降低。供水危机令丰禾也跌 −15%、晨星跌 −13.5%，次级关联过重。

3. **同业多个商品类型重复累加暴露。** 水处理维护按 WATER +35 与净水用品 +25 分别贡献清泉 −11.375%、−8.125%，合计 −19.5% 后截成 −15%。动员同时修正 WEAPON 与 ARMOR，也会重复同一行业权重。建议在事件层合并行业暴露并按严重程度定上限，再决定是否保留多商品叠加。

4. **类型漏映射。** 实际目录出现但当前未映射的标签是 `WATER_RATION`、`BREVAGE`、`SEED`、`HOUSEHOLD_GOOD`、`NARCOTIC`。日用品过剩、上层区遭劫后的日用品流入、日用品救济因此完全没有直接股价影响。补别名前应先处理行业重复累加，否则直接补水类标签会进一步扩大冲击。

5. **重大非价格事件遗漏。** 戒严的原生 `isLockDown=true`，股市却直接为 0；游客涌入、安保预算、严打和检查站同样没有规则。可优先补物流、商贸和防务公司的独立事件表。背景新闻正文明确影响甚微的，继续为 0 更合适。

6. **行业覆盖不均。** 聚合材料为 0 个，晨星物流有 20 个；现有 24 个有影响事件中，19 个只有负向冲击、5 个只有正向冲击，没有同一事件公司间涨跌分化。永久保留部分余波的机制可能放大偏向，但实际趋势还取决于事件触发频率，不能仅凭目录计数断言持续下跌。

7. **动态规则按事件 ID 缓存。** 已生成的 v2 `derived-price` 规则不随同 ID 后续实例重新读取参数；若其他 Mod、难度或游戏版本改变原生修正，可能沿用旧幅度。当前静态工厂的固定值下不必然触发这个问题。

## 主冲击之后如何变化

- 有限时长事件从首次观察日至实际结束前随机一天大跳；未知时长/永久事件使用默认 5 日计划窗口。提前结束会取消尚未发生的大跳。
- 大跳前每日 65% 概率小幅预热，按主冲击幅度的 5% 取目标，单日不超过 0.5%。
- 大跳后小幅延续，按主冲击幅度的 10% 取目标，单日不超过 0.75%。预热与延续共用主冲击绝对值 25% 的因子预算，不会每天重复完整主冲击。
- 同一公司全部事件的预热、延续、恢复合并后，每日净漂移限制为 ±1%；各事件的一次主冲击不受此限，也不受普通每日 ±3% 限制。两个 −15% 主冲击同日可复利合成 −27.75%。
- 结束后，每日尝试修复到目标剩余差额的 25%，仍受 ±1% 合并限制；最终保留该实例已实现总偏移的随机 20%～50%。这个保留比例同一实例各公司共用，且保存后不重抽。
- 长期保留的是事件因子及估值锚点偏移，不保证包含每日随机、成交、其他事件的股票最终绝对价格永远低于/高于发生前价格。

当前兼容策略只纠正尚未大跳的实例；已大跳的不会反向重跳或改写持仓与历史。因此加载最新版后仍可能看到旧方向的延续/修复；要验证新表，需观察新的发生实例或尚未大跳的实例。本次没有修改或重置存档。存档观察不是本次启动游戏的运行验收。
